# Handcrafted Haven

Handcrafted Haven is a full-stack web application developed as part of the **WDD 430: Web Full-Stack Development** course at BYU–Idaho. The application provides an online marketplace where artisans can showcase and sell handcrafted products while customers can discover, review, and purchase unique handmade items.

## Project Goals

The goal of Handcrafted Haven is to:

* Provide artisans with a platform to showcase their craftsmanship.
* Allow customers to browse and discover handcrafted products.
* Support secure product listings and seller profiles.
* Build a responsive, accessible, and user-friendly marketplace.
* Practice collaborative software development using Git and GitHub.

## Features

* Seller authentication and profiles
* Product listings with images, descriptions, and pricing
* Product catalog with search and filtering
* Customer reviews and ratings
* Responsive design
* Accessible user interface (WCAG 2.1 AA)
* SEO-friendly pages

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/ericayanru-dev/handcrafted-haven.git
```

### Navigate to the Project

```bash
cd handcrafted-haven
```

### Install Dependencies

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```
